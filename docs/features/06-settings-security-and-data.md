# 设置、个性化与本地数据

## 状态

- 里程碑：MVP
- 当前状态：`specified`
- 依赖：app_setting、设计令牌、连接/端点/模型配置、RetryPolicy、导入导出、诊断

## 用户问题

用户需要把 Eternal Chat 调整成自己的工作环境：主题、字体、密度、布局、消息样式、快捷键、默认端点/模型、聊天行为和本地数据操作都应可控，而不是被固定成单一厂商客户端。

## 目标

- 提供通用、外观、布局、聊天、连接默认值、数据、开发者和关于设置。
- 支持全局设置，并为适合的选项预留工作区或会话覆盖。
- 所有视觉设置可即时预览、恢复当前作用域默认值和重置全部。
- 管理应用级自动重试默认值，并显示 endpoint 覆盖后的最终结果。
- 提供本地数据位置、导入导出、索引重建和清理入口。
- 让请求预览、上下文检查器、原始事件和性能诊断可按需开启。

## 非目标

- 当前不设计 API Key、token 或其他认证值的最终持久化方案。
- 当前不把 keyring、日志脱敏、权限、签名更新或隐私合规作为 MVP 前置条件。
- MVP 不做云账号设置或跨设备设置同步。
- MVP 不允许设置页直接执行任意脚本。

## 设置分区

### 通用

- 启动行为、语言预留和更新检查入口。
- 默认连接、endpoint、protocol profile 和模型。
- `Enter` 发送行为、命令面板和快捷键覆盖。
- 设置搜索与“恢复默认”操作。

### 外观

- light/dark/system 与自定义主题色板。
- UI 字体、正文字体、代码字体、字号和行高。
- compact/comfortable/spacious 密度。
- 正文阅读宽度、代码主题、Markdown 和数学公式显示偏好。
- 动效强度、滚动行为、透明材质强度和系统 reduced-motion/reduced-transparency 跟随。

主题切换必须避免整页亮度突变。所有最长字体名、主题名和模型名在窄窗口中可截断、换行或通过 tooltip 查看，不得撑破布局。

### 布局

- 左侧栏宽度、默认折叠和会话列表密度。
- 右侧面板宽度、默认位置、自动折叠和小窗口抽屉行为。
- 用户/AI 消息对齐、背景强度、正文最大宽度和元信息显示。
- 思考、工具、来源、usage 和错误详情的默认折叠策略。

拖动宽度时 1:1 跟随指针；释放后继承速度并吸附到合法范围。动效可以随时打断，reduced motion 下即时落位。

### 聊天

- 默认 system prompt、参数和工具开关。
- 自动标题开关。
- 窗口关闭时流式行为。
- 上下文策略显示，MVP 默认为 lossless。
- 自动重试总开关、最大次数、基础/最大延迟和总预算；endpoint 可以在高级设置中覆盖。
- 明确提示中转站可能已处理但未返回响应，自动重试无法保证不重复计费。

### 连接默认值

- 默认连接、端点、协议 profile 和模型分别选择，不把它们合并成一个厂商下拉框。
- 显示最终 host:port/path、profile revision 和最近兼容探测状态。
- 认证 Header/Query/Body 字段从端点配置进入；值如何保存由后续安全专题决定。

### 数据

- 应用数据目录。
- 导出全部/单会话。
- 导入。
- 重建搜索索引。
- 清理无引用 artifact。
- 删除全部本地数据，使用明确范围确认。

“重置设置”与“删除会话数据”必须分开，不能一个按钮全部清空。

### 开发者

- 请求预览和逐字段来源。
- 上下文检查器。
- 原始事件追踪。
- 参数兼容探测。
- 性能诊断。
- 数据完整性检查。

### 关于

- 版本、平台、WebView。
- 官方文档入口与最近 preset 核对日期。
- 项目许可证、第三方声明与[鸣谢](../../ACKNOWLEDGEMENTS.md)。
- 在许可证尚未决定时显示“开源许可证待发布前确定”，不得显示虚构许可证。

## 保存与作用域

- 设置项必须声明作用域：global、workspace 或 conversation。
- 会话覆盖高于工作区，工作区高于全局。
- UI 显示当前值来源；重置当前作用域后立即回退到下一层。
- 主题、字体、密度、布局和动效修改即时预览；破坏性数据操作不做即时执行。
- schema revision 更新不得覆盖用户自定义主题、布局或快捷键。

## 数据清理

破坏性操作必须：

1. 显示具体范围。
2. 说明不可恢复性或可用备份。
3. 要求明确确认。
4. 关闭 active stream。
5. 事务删除数据库数据。
6. 延迟清理文件并报告失败。

## UI

- 使用左侧设置导航或 tabs，不把所有设置堆在单页卡片中。
- switch 用于布尔，select/menu 用于选项，stepper/slider 用于数值，swatch 用于颜色，图标按钮用于清理、打开目录和重置。
- 陌生图标有 tooltip 和 `aria-label`。
- 设置保存状态在页面内清楚显示，不用大量 toast 代替持久状态。
- pointer-down 立即反馈；sheet 从触发项展开并沿相同路径关闭，焦点返回触发项。
- 预览区域与控制区不互相推动布局，字体和密度变化不能遮挡操作按钮。

## 错误

- 数据目录不可写：进入只读/恢复状态。
- 导出失败：保留明确错误和可重试入口。
- trace 超限：按当前诊断策略停止或轮换并显示状态。
- 主题/字体值无效：保留输入并回退到最后可渲染值，不让设置页空白。
- endpoint/model/profile 引用失效：显示具体缺失对象并引导重新选择，不按名称猜测替代项。

## 测试

- 设置持久化、作用域优先级、重置和默认值。
- 主题、字体、密度、列宽、面板、消息样式和折叠规则即时预览。
- pointer-down、拖拽、可中断 spring 和 reduced motion。
- RetryPolicy 默认值、重置、endpoint 覆盖和非法范围校验。
- 默认连接/endpoint/profile/model 分离，显示名称变化不改请求路由。
- 导入导出、索引重建和删除范围事务。
- 请求预览、参数探测和性能诊断开关。
- 深浅主题、窄窗口、200% 缩放和键盘操作无重叠。

## 验收标准

- 用户能深度定制主题、字体、密度、布局、消息样式、折叠策略、动效和快捷键，并能预览、分层重置。
- 用户能分别选择默认连接、端点、协议 profile 和模型，不受厂商名硬编码限制。
- 设置修改在重启后保持，作用域来源可见。
- 自动重试设置能说明应用默认与 endpoint 覆盖的最终生效值。
- 破坏性本地数据操作不会因误触立即执行。
- 凭据保存、安全和隐私仍明确标记为后续专题，不成为本功能的隐藏门禁。

安全范围见 [安全与隐私专题](../SECURITY_AND_PRIVACY.md)，当前状态为 `deferred`。
